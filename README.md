# HELOC Mortgage Payoff Plan

Single-file web app that tracks a HELOC and a mortgage payoff:

- HELOC: log payments, statement interest charges and draws; daily-interest projection on the statement cycle; rate changes
- Mortgage: log principal / interest / escrow per payment; monthly amortization
- Amortization schedules, extra-payment and one-time what-ifs, interest paid and saved

No personal data is stored in this repo. Opened from GitHub Pages, data stays in the browser on that device (use Copy backup / Restore in settings).
